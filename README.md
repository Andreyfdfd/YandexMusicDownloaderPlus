# Yandex Music Downloader Plus

Персональная PowerShell-оболочка для `yandex-music-downloader` в Windows. Проект сохраняет привычный сценарий загрузки в локальную музыкальную библиотеку и позволяет развивать/исправлять оболочку независимо от самого стороннего загрузчика.

> Репозиторий рассчитан на личное использование. Оставляйте его приватным: скрипт по умолчанию содержит ссылку на персональный плейлист «Мне нравится». **Токен в код не добавлять.**

## Возможности текущей рабочей версии

- Запуск скачивания, обновление установленного загрузчика и резервная попытка для одного проблемного трека.
- По умолчанию AAC/M4A 192 кбит/с; доступен FLAC, если поток поддерживается для трека и аккаунта.
- Пропуск уже существующих файлов через `--skip-existing`.
- Отображение строк загрузчика в основном окне по мере обработки и запись вывода в лог.
- После каждого прохода сравнивает аудиофайлы в целевой папке до и после запуска: показывает новые/изменённые файлы, новые файлы нулевого размера и пути, указанные загрузчиком, для которых файл не появился или не изменился.
- Если есть данные по отдельным файлам, создаёт `file-outcomes-*.csv`: путь, статус наблюдения, наличие до/после, размер до/после и время изменения. В отчёт также попадают новые/изменённые аудиофайлы, не упомянутые в выводе загрузчика.
- Строки вида `не доступен для скачивания` распознаются отдельно от общих ошибок.
- При обнаружении недоступных треков создаётся `unavailable-*.csv` с позицией в плейлисте, отображаемым названием, сообщением, числом повторных обнаружений и проходами, на которых трек был отмечен.
- Отдельный `errors-*.txt` содержит сводку недоступных треков и прочих диагностических строк.
- Пункт меню 5 позволяет повторно проанализировать существующий `download-*.log` и пересоздать CSV без обращения к Яндекс Музыке и без загрузки файлов.
- Одна лишь недоступность треков не запускает автоматический повтор всего плейлиста; повтор предлагается при других ошибках, которые могут быть временными.
- Логи и отчёты сохраняются в `logs/` (эта папка исключена из Git).
- По желанию токен сохраняется между запусками с помощью Windows DPAPI в `%APPDATA%\YandexMusicDownloaderPlus\token.dpapi`. Файл находится вне репозитория.
- Операции DPAPI выполняются напрямую через системный Windows API, поэтому чтение токена не зависит от загрузки `Microsoft.PowerShell.Security`.
- Пункт меню 6 проверяет расшифровку сохранённого токена офлайн: не показывает секрет и не обращается к Яндексу.
- Пункт меню 7 проверяет полный цикл DPAPI «расшифровать → зашифровать во временный файл → снова расшифровать»; исходный `token.dpapi` не изменяется, временный файл удаляется, сеть не используется.
- Резервная попытка использует отдельную папку, чтобы не смешивать непроверенные результаты с основной библиотекой.

## Запуск

Запустите `Запустить_загрузку.bat` и следуйте подсказкам. Не передавайте токен в чат, не записывайте его в `.ps1`/`.bat` и не коммитьте логи или файл `token.dpapi`.

## Известные ограничения

1. Счётчик позиции вида `[1866/6737]` показывает позицию в исходном списке, а не число успешных загрузок. Оболочка сравнивает аудиофайлы до и после прохода и анализирует пути из вывода загрузчика, но точное число молча пропущенных файлов определить нельзя, если upstream не сообщает об этом отдельно. Ненулевой размер файла сам по себе не подтверждает его полную длительность или целостность.
2. Некоторые треки могут не отдаваться используемым загрузчиком, даже если доступны для прослушивания в веб-интерфейсе. Отчёт фиксирует такие случаи; для дальнейшей диагностики их нужно проверять отдельно.
3. CSV объединяет повторные сообщения об одной позиции плейлиста и сохраняет количество попыток. Если меняется плейлист или порядок его элементов между проходами, сравнивайте URL и полный лог перед трактовкой индексов.

## Безопасность

- Не хранить токен в незашифрованном `.txt`/`.json`: это превращает файл в готовый ключ доступа. Текущий вариант использует DPAPI, привязанный к профилю Windows.

- Никогда не добавляйте токены, cookies, DPAPI-файлы, логи или скриншоты с секретами в Git.
- Перед `git push` проверяйте staged changes.
- Токен загрузчика передаётся стороннему процессу как аргумент командной строки; локальные средства просмотра процессов с достаточными правами могут его увидеть.
- Устанавливайте обновления самого загрузчика только из его официального репозитория: https://github.com/llistochek/yandex-music-downloader

## Структура

- `YandexMusicDownloader.ps1` — оболочка PowerShell.
- `Запустить_загрузку.bat` — запуск оболочки.
- `ПРОЧТИ_МЕНЯ.txt` — подробная инструкция.
- `.gitignore` — исключает логи, токены и локальные временные файлы из Git.
