ЯНДЕКС МУЗЫКА — DOWNLOADER PLUS 0.3.0
======================================

1. УСТАНОВКА

1. Скачай YandexMusicDownloaderPlus-Setup-0.3.0.exe из GitHub Releases:
   https://github.com/Andreyfdfd/YandexMusicDownloaderPlus/releases/tag/v0.3.0
2. Запусти установщик. Выбери папку программы, компоненты и каталог музыкальной библиотеки.
3. По умолчанию музыка сохраняется в %USERPROFILE%\Music. Папку можно перенести на другой диск. Её создание во время установки можно отключить.
4. После установки открой Downloader Plus из меню Пуск или ярлыка на рабочем столе.
5. Для продвинутой диагностики в меню Пуск остаётся пункт «Консольная версия».

2. ПЕРВЫЙ ЗАПУСК

1. Открой раздел «Настройки».
2. Вставь токен Яндекс Музыки в поле токена и нажми «Сохранить токен».
3. Токен будет сохранён в профиле текущего пользователя Windows через DPAPI. GUI и консольная версия используют один и тот же файл:
   %APPDATA%\YandexMusicDownloaderPlus\token.dpapi
4. Укажи музыкальную папку и нажми «Сохранить настройки».
5. Перейди в «Загрузка музыки», вставь ссылку и выбери качество/тексты песен. Нажми «Начать загрузку».

3. ГРАФИЧЕСКОЕ ПРИЛОЖЕНИЕ

- «Загрузка музыки» — запуск загрузки, выбор AAC/M4A, FLAC или MP3 (если поддерживается), текстов песен и задержки запросов.
- «Экспорт библиотеки» — экспорт списка треков без скачивания аудио.
- «Восстановление» — выбери предыдущий журнал и восстанови только неудачные позиции.
- «Журналы и отчёты» — открывай логи и CSV-отчёты.
- «Настройки» — управление токеном и папкой музыки.

Во время работы приложение показывает вывод backend, позицию композиции в очереди и прогресс. Кнопка «Отменить» запрашивает безопасную отмену; процесс может завершиться не мгновенно, если текущий сетевой запрос уже выполняется. Уже сохранённые треки не удаляются.

4. РЕЗЕРВНЫЕ BACKEND-МОДУЛИ

Порядок попыток:
1. Основной yandex-music-downloader.
2. Независимый API-клиент, встроенный в программу.
3. yt-dlp с cookies выбранного браузера — только если пользователь разрешил этот способ в настройках и подтвердил его перед запуском.

Независимый API-клиент поддерживает отдельные треки, альбомы, плейлисты и постраничный список композиций исполнителя.

Программа не использует переключение backend для обхода отказов доступа, ограничений подписки/региона, DRM, HTTP 401/403/429 или сообщения not-allowed. Если сервис сам не отдаёт полный поток, резервный клиент не может гарантировать загрузку.

5. ЭКСПОРТ СПИСКА МУЗЫКИ

1. Открой раздел «Экспорт библиотеки».
2. Вставь ссылку на плейлист, альбом или исполнителя.
3. Выбери каталог и нажми «Создать резервную копию».
4. Программа создаст:
   - CSV — для переноса в Soundiiz и совместимые медиасервисы;
   - JSON — полный резервный формат Downloader Plus;
   - TXT — строки «Исполнитель - Название»;
   - XML — структурированный список композиций.

Сохраняются название и версия трека, исполнители, альбом, длительность, ISRC при наличии, позиция в источнике, ID и ссылка. Аудио не скачивается, токен не включается в экспорт. По умолчанию используется Документы\YandexMusicBackups.

6. ВОССТАНОВЛЕНИЕ

1. Открой раздел «Восстановление».
2. Выбери лог неудачного запуска.
3. Нажми «Восстановить выбранный запуск».
4. Downloader Plus формирует очередь проблемных треков и последовательно проверяет основной CLI, независимый API-клиент и (только с отдельным согласием) браузерный yt-dlp backend.
5. Перед помещением резервного файла в музыкальную библиотеку проверяются его читаемость и длительность.
6. Неполные или сомнительные файлы сохраняются в соседнем каталоге карантина/staging. Они не удаляются автоматически и не должны молча заменять исправные композиции.

Если у трека нет надёжной длительности в метаданных, автоматическая проверка не сможет доказать его полноту. Такой файл остаётся для ручной проверки.

7. ОТЧЁТЫ

В папке программы logs находятся:
- download-*.log — полный журнал запуска;
- source-inventory-*.csv — снимок состава источника;
- library-status-*.csv — список удалённых из источника и проблемных позиций;
- unavailable-*.csv — сообщения о недоступных треках;
- file-outcomes-*.csv — наблюдения по аудиофайлам;
- retry-queue-*.csv и recovery-results-*.csv — очередь и результаты восстановления;
- errors-*.txt — сводка диагностических сообщений.

Сравнение удалённых треков начинается после первого успешного снимка источника. Если API не позволяет получить полный список, загрузка может продолжиться, но сравнение состава будет неполным.

8. КОНСОЛЬНАЯ ВЕРСИЯ

Консольная версия сохранена для диагностики и продвинутых сценариев. Её можно открыть из меню Пуск («Консольная версия») или запустить Запустить_загрузку.bat из каталога программы.

В консольном меню:
- 1 — скачать музыку;
- 2 — обновить основной загрузчик и выйти;
- 3 — обновить основной загрузчик и начать загрузку;
- 4 — попробовать отдельный резервный источник для одного трека;
- 5 — анализ существующего журнала;
- 6/7 — проверки DPAPI токена;
- 8 — повтор незавершённой загрузки;
- 9 — последовательное восстановление неудачных треков;
- 10 — экспорт состава библиотеки без аудио.

9. БЕЗОПАСНОСТЬ И ОГРАНИЧЕНИЯ

- Не отправляй токен, cookies, token.dpapi, личные ссылки и полные логи третьим лицам.
- Не добавляй токены и журналы в Git.
- Токен DPAPI привязан к текущему Windows-пользователю; на другом ПК/профиле он может не расшифроваться.
- Bundled launcher не помещает токен основного CLI в аргументы командной строки.
- Браузерный fallback использует cookies профиля браузера, поэтому перед ним требуется отдельное согласие.
- Не каждую композицию можно получить в полном качестве. Доступность прослушивания не всегда означает право/возможность получения полного файла через сторонний клиент.
- Ненулевой размер или совпадающая длительность не являются абсолютным доказательством отсутствия повреждений.

10. РАЗРАБОТКА И ДИАГНОСТИКА

- PowerShell-движок: YandexMusicDownloader.ps1
- WPF-приложение: ui\DownloaderPlus
- Python-инвентаризация/экспорт: tools\source_inventory.py
- Независимый API backend: tools\backends
- Сборка установщика: installer\build.ps1
- Windows CI: .github\workflows\release-windows-installer.yml

GitHub CI проверяет синтаксис, тесты сериализации экспорта, импорты backend-модулей, сборку GUI/установщика и тестовую установку. Он не подключается к личному аккаунту Яндекса; перед реальной массовой загрузкой проверь один трек и затем небольшой плейлист.
