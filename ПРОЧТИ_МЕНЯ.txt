ЯНДЕКС МУЗЫКА — DOWNLOADER PLUS
================================

ЗАПУСК
1. Распакуй архив в отдельную папку.
2. Для первого теста в основном режиме укажи ссылку на один трек и отдельную временную папку. Когда убедишься, что файл полный и теги корректны, запускай полную синхронизацию «Мне нравится».
3. Запусти «Запустить_загрузку.bat» двойным щелчком.
4. Для обычной загрузки нажми 1. При желании сначала выбери 2, чтобы обновить установленный загрузчик из его репозитория, или 3 — обновить и сразу перейти к загрузке.
5. При первом запуске вставь токен в скрытое поле. По умолчанию скрипт предлагает сохранить его зашифрованным средствами Windows DPAPI для следующих запусков текущего Windows-пользователя. Токен не хранится в открытом виде в .ps1/.bat и не записывается в лог. Расшифровка/сохранение выполняются через системный Windows DPAPI и не требуют загрузки `Microsoft.PowerShell.Security`.
6. Если основной загрузчик не справляется с конкретным треком, перезапусти пакет и выбери пункт 4 — резервный источник для одного трека.
7. Пункт 5 анализирует существующий `download-*.log`, создаёт CSV недоступных треков и сводку без запуска скачивания и без запроса токена.
8. Пункт 6 проверяет, удаётся ли расшифровать сохранённый `token.dpapi`. Он не выводит токен и не подключается к Яндексу.
9. Пункт 7 проверяет полный цикл расшифровки и повторного шифрования сохранённого токена через временный файл. Исходный `token.dpapi` не изменяется, файл проверки удаляется, токен не выводится, сеть не используется.

ЧТО ИЗМЕНЕНО
- Исходная логика сохранения и ссылка на коллекцию «Мне нравится» по умолчанию сохранены.
- По умолчанию остаётся качество 1 — AAC/M4A 192 кбит/с, как в исходной команде. Дополнительно можно выбрать FLAC (quality 2).
- --skip-existing обязателен: если установленная версия его не поддерживает, запуск отменяется. Это защита от повторного скачивания уже имеющихся файлов.
- Задержка 0 секунд по умолчанию ради скорости; если API начинает ограничивать запросы, можно выбрать 1 секунду.
- Увеличен timeout до 30 секунд; для сетевых ошибок используются до 20 попыток и пауза 3 секунды между ними — только если параметры поддерживаются установленной версией.
- Включена передача UTF-8 в Python, чтобы названия треков с редкими символами не приводили к ошибке кодировки в Windows.
- Включён `PYTHONUNBUFFERED=1`: вывод загрузчика проходит в основное окно по мере обработки треков, а те же строки одновременно записываются в лог. Ранее Python мог буферизовать строки до завершения всего прохода. Уже существующие треки загрузчик пропускает молча, поэтому отображаются прежде всего реально обрабатываемые/скачиваемые треки.
- Если обнаружены другие диагностические ошибки, скрипт может предложить повторный проход. Одна лишь строка «не доступен для скачивания» записывается в CSV и не запускает повтор всей коллекции автоматически. Благодаря --skip-existing уже скачанные файлы должны пропускаться.
- Для FLAC можно повторить попытку с AAC/M4A 192 кбит/с. Это помогает только в случаях, когда ошибка связана с конкретным доступным форматом/качеством; это не гарантирует загрузку недоступного трека.
- Логи пишутся в папку logs рядом со скриптом. Создаётся errors-*.txt со сводкой диагностики и unavailable-*.csv со списком недоступных треков (позиция, название, число повторных обнаружений, проходы и сообщение загрузчика).
- Можно вставить прямую ссылку на отдельный трек вместо плейлиста, чтобы диагностировать один проблемный трек.
- Пункт 4 использует отдельный backend yt-dlp + плагин Yandex Music и авторизацию из браузера. Он сохраняет найденный трек отдельно в `D:\Music\_YandexMusic_Fallback`, чтобы не смешивать его автоматически с основной библиотекой. Внутри этой папки используется download archive для пропуска повторно обработанного ID.
- Резервный backend требует действующую браузерную сессию и аккаунт с правом на полное воспроизведение. Если он обнаружит `smart_preview`/короткий preview, не считай его полноценной песней — проверь длительность вручную.
- Не удаляет локальные файлы, которых больше нет в Яндекс Музыке.

ОБНОВЛЕНИЕ ЗАГРУЗЧИКА
Пункт 2/3 запускает pip update из официального репозитория проекта:
https://github.com/llistochek/yandex-music-downloader
Скрипт не обновляет пакет автоматически без выбора этого пункта. Основная ветка проекта может содержать изменения, которые ещё не опубликованы как стабильный релиз; если после обновления стало хуже, используй pip/venv для возврата к известной рабочей версии.

О ПРОБЛЕМЕ «ТРЕК МОЖНО СЛУШАТЬ, НО НЕ СКАЧАТЬ»
Доступность воспроизведения в интерфейсе и возможность получить полный файл через сторонний загрузчик — не одно и то же. Ошибка может быть связана с изменением API, конкретным форматом/потоком, токеном, регионом или ограничениями прав. Повторный проход помогает при временных сетевых сбоях; переход с FLAC на AAC может помочь, когда проблема только в формате. В октябре 2026 года в репозитории основного загрузчика открыт issue о `playlist-not-found` для ссылок на плейлисты; поэтому при такой ошибке скрипт предлагает попробовать адрес `/users/ЛОГИН/playlists/3`. См. https://github.com/llistochek/yandex-music-downloader/issues/159. Для одного упрямого трека можно попробовать резервный backend из пункта 4, который понимает ссылки `playlists/lk.…` и предупреждает о коротких preview-файлах; см. https://github.com/fgsfds1/yt-dlp-yandex-music-plugin. Это не гарантирует исправление каждого трека. Не отправляй лог или ссылку, если они содержат токен; перед публикацией проверь и удали секреты.

ФОРМАТЫ И КАЧЕСТВО
- --quality 1 — обычно AAC 192 кбит/с в контейнере M4A; это исходный формат в прежней команде, не MP3.
- --quality 2 — FLAC, если он доступен для выбранного трека и аккаунта.
- MP3 предлагается только если конкретная установленная версия явно поддерживает --force-mp3. Скрипт не переименовывает M4A в MP3 и не выдаёт перекодирование за lossless.

ВАЖНО О ТОКЕНЕ И ЕГО СОХРАНЕНИИ
- Токен можно сохранить между запусками. Скрипт шифрует его Windows DPAPI (ConvertFrom-SecureString без ключа) и хранит файл в %APPDATA%\YandexMusicDownloaderPlus\token.dpapi. В открытом виде он не записывается в файлы проекта и логи.
- При следующем запуске нажми Enter, чтобы использовать сохранённый токен. Введи N, чтобы указать новый токен, либо D, чтобы удалить сохранённый токен и ввести новый. При вводе нового токена подтверждение сохранения по умолчанию — да.
- Шифрование привязано к профилю Windows. На другом ПК или под другим пользователем файл может не расшифроваться. Если нужно удалить токен, выбери D в запросе скрипта или удали файл token.dpapi в указанной папке AppData.
- Это защищает токен в состоянии покоя, но не полностью скрывает его во время загрузки: установленный загрузчик получает токен как аргумент командной строки. Локальные средства просмотра процессов с достаточными правами теоретически могут увидеть аргументы.
- Токен из ранее присланного текстового файла считай раскрытым и отзови/перевыпусти его перед использованием. Не вставляй токен в .ps1/.bat, логи или чат.

ОГРАНИЧЕНИЕ
Этот пакет не меняет сам механизм получения аудиопотока и не использует сторонние сайты с неофициальными копиями. Он обновляет/настраивает существующий загрузчик, делает повторные попытки и помогает собрать диагностику. Треки, для которых сервис не отдаёт подходящий ресурс стороннему клиенту, могут остаться недоступными.
